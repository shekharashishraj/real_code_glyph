📚 How It Works

Core Technique

This tool implements the font manipulation technique from the research paper arXiv:2505.16957. It modifies TrueType font glyph mappings so that characters visually appear as one thing but contain different Unicode values.

Formula: GlyphIndex = idDelta + Unicode Example: • Unicode 'b' (0x62) → Modified to display glyph of 'a' • Looks like: 'a' • Copy-paste reveals: 'b' • Visual appearance ≠ Digital content

🌐 API Endpoints

GET /api/health Check server health
POST /api/load-font Upload TTF font file
POST /api/extract-text Extract text from PDF
POST /api/preview-mappings Preview character mappings
POST /api/generate-modified-font Generate modified font file
GET /api/get-mappings Get current mappings

⚡ Quick Examples

Check API Health

curl http://127.0.0.1:5001/api/health

Upload a Font

curl -X POST -F "font=@your_font.ttf" \ http://127.0.0.1:5001/api/load-font

Generate Modified Font

curl -X POST \ -H "Content-Type: application/json" \ -d '{ "font_name": "your_font.ttf", "mappings": [ {"original": "hello", "replacement": "world"} ] }' \ http://127.0.0.1:5001/api/generate-modified-font \ --output modified_font.ttf
