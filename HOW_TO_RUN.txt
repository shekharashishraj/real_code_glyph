METHOD 3: TEST WITH CURL COMMANDS
================================================================================

1. Check API health:
   curl http://127.0.0.1:5001/api/health

2. Download a test font:
   curl -L -o OpenSans-Regular.ttf \
     "https://github.com/google/fonts/raw/main/apache/opensans/OpenSans-Regular.ttf"

3. Upload font to API:
   curl -X POST -F "font=@OpenSans-Regular.ttf" \
     http://127.0.0.1:5001/api/load-font

4. Generate modified font:
   curl -X POST \
     -H "Content-Type: application/json" \
     -d '{
       "font_name": "OpenSans-Regular.ttf",
       "mappings": [
         {"original": "hello", "replacement": "world"}
       ]
     }' \
     http://127.0.0.1:5001/api/generate-modified-font \
     --output modified_font.ttf

WHAT THIS TOOL DOES
================================================================================

Implements font manipulation technique where:
  • Text VISUALLY appears as one thing (e.g., "hello")
  • But UNICODE content is different (e.g., "world")
  • Copy-paste reveals actual Unicode characters
  • Useful for defensive security research

Based on research paper: arXiv:2505.16957
"Invisible Prompts, Visible Threats: Malicious Font Injection"

TROUBLESHOOTING
================================================================================

Q: "Not Found" error when accessing http://127.0.0.1:5001
A: Don't access the root URL. Use API endpoints like:
   http://127.0.0.1:5001/api/health

Q: Font loading failed
A: Make sure you're using .ttf files (not .ttc collections)
   Download: curl -L -o font.ttf https://github.com/...

Q: API server not responding
A: Check if it's running:
   ps aux | grep font_manipulation_api.py
   Restart: python3 font_manipulation_api.py

Q: Missing dependencies
A: Install: pip3 install fonttools PyPDF2 reportlab Flask Flask-CORS
